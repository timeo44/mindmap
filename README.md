# Mindmap

Einfacher Mindmap-Editor im Browser – eine einzige HTML-Datei, ohne Server und ohne Anmeldung.

**Live:** https://timeo44.github.io/mindmap/

## Funktionen
- Punkt anklicken und lostippen, **Tab** = Unterpunkt, **Enter** = gleiche Ebene
- Punkte per Drag & Drop umhängen, Äste einfärben, ein- und ausklappen
- **Meine Mindmaps:** beliebig viele Mindmaps, automatisch im Browser gespeichert (localStorage)
- Sicherung aller Mindmaps als JSON herunterladen und auf einem anderen Gerät laden
- Export als PNG-Bild, als eingerückte Liste oder als eigenständige HTML-Datei
- Import aus einer eingerückten Liste

Die Mindmaps bleiben auf dem eigenen Gerät; nichts wird an einen Server geschickt.
